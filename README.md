# Class Desk

Class Desk is a Flutter app for tuition teachers. The dashboard shows collections, balances, and promised dates. Open Students
to add a student, then Fees to create a monthly fee and record a payment.
Settings contains the theme controls and style guide.

## Run and test

Run from the project directory with Flutter on PATH.

```powershell
flutter pub get
flutter analyze
flutter test
flutter run -d chrome --web-port 8080
```

On Android, use `flutter devices` to find a connected phone, then run
`flutter run -d DEVICE_ID`. Android uses the native SQLite plugin. Web uses
SQLite WebAssembly and IndexedDB. Keep the same web origin, including the
port, when testing persistence.

The checked-in web worker and WASM binary are generated by sqflite's setup tool.
After updating the SQLite web dependencies, regenerate them with
`dart run sqflite_common_ffi_web:setup --force`.

## Local storage

Open one `LocalDatabase` and share it across features. Use
`repository(LocalTable.students)` and the equivalent repository for each table.
`seedDemoData()` is opt-in, transactional and only runs for an empty roster.
Keep demo data separate from a real roster when testing.

Money values use integer paise. Calendar dates use `YYYY-MM-DD`, fee periods
use `YYYY-MM`, and timestamps use Unix microseconds. A soft delete marks
the row pending for sync. Linked fees, payments and promises stay in SQLite
and reappear when their parent is restored.
## WhatsApp and homework

Open a fee with a balance and choose **Send WhatsApp reminder**. Preview or
edit the template before opening the parent’s chat. Create homework under
**Homework**, then choose **Send to parents** to open the batch’s queue.
The message can also be copied for use in a group.

After sending in WhatsApp, return to Class Desk and choose **Mark as sent**.
Homework confirmations are saved in SQLite and restored when the queue is
reopened. The app records the teacher's confirmation. WhatsApp delivery status
is unavailable through click-to-chat links.

## Mobile reminders and sync address

On Android, use **Settings → Monthly fee reminders** and allow notifications.
Class Desk schedules the unpaid fee total for the first of each month around
9 a.m. local time. It updates the amount after local fee changes and sync.
Homework can target an entire batch or one student.

Set the public API address in backend/.env as CLASS_DESK_SYNC_URL, then
run flutter-class-desk.ps1 to pass just that address to Flutter. For
Android, the script accepts an HTTPS address. The sync token is entered
once per device and saved in platform secure storage. The Neon URL and
the sync token stay out of the build configuration.

Run pnpm run migrate and restart the backend when deploying this update.
The backend requires an updated app before syncing individual homework.
